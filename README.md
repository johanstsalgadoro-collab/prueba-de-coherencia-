# Presentación web — Prueba de coherencia del proyecto

Universidad ECCI · Investigación, Desarrollo e Innovación II · 2026

## Alcance

Presentación web en 15 diapositivas sobre la coherencia del proyecto **Ruta inteligente híbrida**, a partir de la matriz de vigilancia tecnológica, estado del arte y portafolio de alternativas previos. Se incluyen cinco preguntas para hacer a otro equipo y la plantilla `REPORTE_PREGUNTAS_RECIBIDAS.md` para diligenciar cuando conozcan las preguntas reales que reciban.

## Abrir localmente

Abrir `index.html` en Chrome, Edge o Firefox. No requiere instalación ni internet.

## Presentación

- Flecha derecha / barra espaciadora: siguiente diapositiva.
- Flecha izquierda: diapositiva anterior.
- `G`: índice de diapositivas.
- `F`: pantalla completa.
- `Home` y `End`: inicio y final.

## Publicar en GitHub Pages

1. Crear un repositorio público en GitHub.
2. Subir **el contenido de esta carpeta** a la raíz del repositorio (incluyendo `index.html`).
3. Ir a Settings > Pages > Build and deployment.
4. Elegir Deploy from a branch, `main`, `/ (root)` y guardar.

## Entregables académicos

1. Presentación del proyecto propio: `index.html`, con sus archivos CSS y JS.
2. Cinco preguntas para el equipo interlocutor: diapositiva 13 (numeración visible 13 / 15).
3. Reporte de respuestas recibidas: plantilla `REPORTE_PREGUNTAS_RECIBIDAS.md`, que deberá completarse después del intercambio.

## Precisión académica

Las metas KPI son propuestas, no resultados obtenidos. Las entrevistas, el piloto y las mediciones de línea base no se presentan como ejecutados. Las cinco preguntas fueron formuladas como propuesta, pues la imagen de instrucciones no incluye cinco preguntas textuales obligatorias.
